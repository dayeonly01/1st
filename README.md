# 1등급 연습기 웹앱

현재 v11 기능을 그대로 웹서버에서 실행하도록 포장한 첫 배포용 프로젝트입니다.

## 내 컴퓨터에서 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm start`
3. 브라우저에서 `http://localhost:3000`

## 인터넷에 배포
이 폴더를 GitHub 저장소에 올린 뒤 Vercel/Render/Railway 같은 Node.js 호스팅에 연결하면 됩니다.
Start command는 `npm start`입니다.

## 중요: AI 필기 지우기
현재 `필기 지우기`는 v11의 브라우저 픽셀 처리입니다. 실제 AI 필기 제거는 아직 연결되지 않았습니다.
다음 개발 단계에서 `/api/remove-handwriting` 같은 서버 API를 추가하고, 인쇄 원문을 보존하는 마스크 기반 모델/서비스를 연결해야 합니다.
API 키는 절대로 public/index.html 안에 넣지 않고 서버 환경변수로 보관해야 합니다.


## v2 추가 기능
- A4 문제지에 자유 텍스트 메모 추가
- 메모 직접 편집 및 자유 이동
- 글자 크기 8~72px 조절: A-/A+ 또는 숫자 직접 입력
- 파란 핸들을 끌어서 글자 크기 조절
- 선택 텍스트 삭제
- PDF/인쇄 시 편집 테두리/핸들 자동 숨김

## v3 텍스트 상자 개선
- 텍스트 상자 선택 시 오른쪽 아래 파란 크기조절 점 표시
- 파란 점을 대각선으로 드래그하면 상자 폭과 글자 크기가 동시에 비례해서 확대/축소
- 텍스트가 여러 줄이 되면 상자 높이는 내용에 맞춰 자동 조절
- 텍스트 본문 클릭은 편집, 상자 여백 드래그는 이동으로 동작 분리

## v4 풀이 칸 기능
- A4 오답 문제지에 `＋ 풀이 칸` 버튼 추가
- 점선이 반복되는 풀이 영역 생성
- 풀이 칸 전체를 드래그해서 원하는 위치로 이동
- 오른쪽 아래 파란 점을 드래그해서 가로/세로 크기 자유 조절
- 여러 개의 풀이 칸을 각각 추가 가능
- 선택한 풀이 칸 삭제 가능
- PDF/인쇄 시 조절 핸들은 숨기고 점선 풀이 칸만 출력

## v5 텍스트/풀이 칸 개선
- 상단 툴바에서 `＋ 텍스트 넣기`, `＋ 풀이 줄 넣기` 버튼만 보이도록 단순화
- 텍스트 글자 크기 숫자 입력 제거: 오른쪽 아래 파란 점 드래그만으로 상자와 글자 크기 동시 조절
- 풀이 칸 클릭 시 작은 줄 수 조절 버튼 표시
- `－ / ＋` 버튼으로 풀이 줄 수를 2~12줄 범위에서 조절
- 풀이 칸은 드래그 이동, 파란 점 드래그로 가로/세로 크기 조절
