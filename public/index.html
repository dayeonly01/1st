🏆 1등급 연습기 오답을 깨끗한 재풀이 문제로

1. 문제집 사진 · 크롭

또는 아래의 ‘문제집 사진을 넣어주세요’ 영역에 사진을 바로 드래그하세요.
사진 위에서 원하는 문제를 드래그한 뒤 마우스를 떼면 크롭 영역이 확정됩니다. 확정된 파란 점선 상자는 더 이상 움직이지 않습니다. 그 상자를 다시 잡아 오른쪽 A4로 드래그하면 확정된 영역의 복사본만 이동합니다.
사진을 드래그하거나 선택해 시작하세요.
※ 필기 자동 정리는 인터넷 전송이나 유료 API 없이 이 브라우저 안에서만 작동합니다. 색연필·채점펜·연한 연필에 효과적입니다. 진한 연필과 인쇄 글씨는 완벽히 구분하기 어려우므로 먼저 ‘약하게’ 또는 ‘보통’을 권장합니다. 결과가 마음에 들지 않으면 되돌리기를 누르세요.

2. A4 오답 문제지

문제를 배치하고, 필요할 때만 ＋텍스트 넣기 또는 ＋풀이 줄 넣기를 사용하세요. 텍스트와 풀이 칸은 오른쪽 아래 파란 점을 드래그해 크기를 조절할 수 있고, 풀이 칸을 클릭하면 줄 수 조절 버튼이 나타납니다.

3. 문제 정보

📖 스캔하면 사진 맨 아래쪽의 독립된 숫자를 페이지 번호 후보로 자동 인식합니다. 페이지 + 문제번호 + 정답은 이 브라우저에 연결 저장되어, 같은 페이지와 문제번호를 다시 입력하면 저장했던 정답을 자동으로 불러옵니다.
